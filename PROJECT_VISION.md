# Mastery Key Coach

## Tagline
Unlock Your Best Self.

## Mission
Help people build discipline and consistency through AI-powered coaching, daily missions, and meaningful rewards.

## Target Users
- Students
- Professionals
- Anyone who wants to improve themselves

## Core Features
- Daily Missions
- AI Coach
- Goal Tracking
- Habit Tracking
- XP & Levels
- Streaks
- Badges
- Shareable Certificates
- Progress Analytics

- Backend: FastAPI
- Database: PostgreSQL
- AI: Gemini API / OpenAI API
- Deployment: AWS
