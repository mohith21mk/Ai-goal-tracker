# AI Goal Coach

## One-Line Description
An AI-powered application that helps users track goals, build habits, analyze progress, and receive personalized coaching.

## Problem Statement
Many people set goals but struggle to stay consistent and understand why they lose progress. Most habit-tracking apps only record completed tasks and do not provide meaningful feedback or personalized guidance. This project aims to combine goal tracking with AI-powered insights and coaching to help users build better habits and achieve their goals.

## Target Users
- Students
- Professionals
- Fitness enthusiasts
- Anyone who wants to improve daily habits

## Core Features
- User Login
- Goal Management
- Habit Tracking
- Daily Journal
- AI Chatbot
- Performance Dashboard
- Weekly Review
