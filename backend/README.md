# AI Goal Coach Backend

This backend provides a starter FastAPI application for the AI Goal Coach project.

## Run locally

1. Create a virtual environment
   - `python -m venv .venv`
   - `.venv\Scripts\activate`
2. Install dependencies
   - `pip install -r requirements.txt`
3. Start the server
   - `python -m app.main`

## Endpoints

- `GET /`
- `POST /api/auth/login`
- `GET /api/users`
- `GET /api/missions`
- `GET /api/progress`
